Это короче медленный аналог Cheat Engine, Art Money и других. Когда сворачиваешь игру срабатывает античит (следит за мышкой и т.д.) меняет значения. Можно удаленно с телеграмма теперь просматривать память приложений, находить нужное, и нужный адрес уже вбивать в нормальную программу для редактирования, просмотра машинного кода.
